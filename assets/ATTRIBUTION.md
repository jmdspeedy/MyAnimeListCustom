# Asset Sources and Attribution

## Aqours 7th Anniversary member artwork

- Copyright notice visible in the source artwork: `©2017 プロジェクトラブライブ！サンシャイン!!`
- Official distribution page:
  <https://www.lovelive-anime.jp/uranohoshi/7thproject-special.php>
- Retrieved: 2026-08-09
- Official usage statement summary: the page distributes nine SNS icons and
  nine smartphone wallpapers and states that visitors may use them freely.
- Project use: non-commercial decorative artwork for a personal MyAnimeList
  anime-list theme.

The project publishes resized WebP derivatives with versioned filenames. It
does not remove the copyright marks embedded in the source artwork.

Original URL pattern:

```text
https://www.lovelive-anime.jp/uranohoshi/img/special/7thproject/{member}_icon.jpg
https://www.lovelive-anime.jp/uranohoshi/img/special/7thproject/{member}_wp.jpg
```

`{member}` is one of `chika`, `riko`, `kanan`, `dia`, `you`, `yoshiko`,
`hanamaru`, `mari`, or `ruby`.

Published derivatives:

- `assets/images/{member}-7th-icon-v1.webp`: 240×240, WebP quality 84.
- `assets/images/{member}-7th-wallpaper-v1.webp`: 360×779, WebP quality 82.
- `assets/images/aqours-collectible-ribbon-v1.png`: generated nine-member UI
  composite derived from the published icon artwork and displayed as the
  decorative status-navigation ribbon.

These files remain subject to the original rightsholder's terms. They are not
released under the repository's code license.
